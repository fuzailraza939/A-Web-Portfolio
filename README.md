# A-Web-Portfolio
Fuzail Raza — Frontend & WordPress Developer Portfolio
A modern, fully responsive personal portfolio built with HTML, CSS & vanilla JavaScript. Features smooth GSAP animations, particle canvas, custom cursor, dark/light theme toggle, and scroll-triggered effects.

🛠️ Tech Stack
HTML5 CSS3 JavaScript GSAP ScrollTrigger

⚡ Performance

Mobile optimized — particles, cursor & heavy effects disabled on mobile
Fonts loaded with preconnect + display=swap
Scripts loaded with defer
Scroll events throttled via requestAnimationFrame
